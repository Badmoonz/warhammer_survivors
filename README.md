# FYRESLAYER: SKAVEN TIDE

MVP-клон Vampire Survivors (2D, пиксель-арт) на **PlayCanvas + TypeScript + Vite**.
Фанатский сеттинг Warhammer Age of Sigmar: дварф-файрслеер против tide скавенов.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
```

Сборка: `npm run build` (типчек + прод-бандл в `dist/`), проверка типов: `npm run check`.

## Управление

- **WASD / стрелки** — движение; оружие стреляет автоматически
- **1/2/3 или клик** — выбор апгрейда на левел-апе
- **R** — рестарт после смерти/победы
- Цель — прожить 5 минут; дальше — endless

Герой: файрслеер-**ближник** — размахивает файрстальной секирой дугой по направлению
движения (со 2-го уровня добавляется обратный замах), плюс рунная огненная нова
(AoE вокруг героя, берётся на левел-апе). Пассивки: урон, скорость, макс. HP/реген,
радиус сбора.

Враги: кланрэты → чумные монахи (паки) → штормвермины → элитные штормвермины →
крысиный огр (первый босс на 2:30, затем каждые 1:15). Элитные штормвермины
появляются с 1:15, затем каждые 40 секунд. Дроп: осколки варпстоуна (XP), сердца (хил).

## Дебаг-флаги (URL)

- `?sheet=1` — страница всех спрайтов (увеличенных ×6)
- `?bot=1` — автопилот (не нужна клавиатура)
- `?god=1` — неуязвимость
- `?t=<секунды>` — начать забег с заданного времени (например `?t=150` — сразу босс)

## Арт

Игра сначала загружает `assets/generated/spritesheet-hd.png`: 51 кадр,
текстуры в 4 раза детальнее при неизменном игровом масштабе. Среди них —
12 кадров атаки героя, 16 кадров атаки монстров и обновлённые пары ходьбы. Затем при необходимости
используются `assets/generated/spritesheet.png`, старый OpenGameArt-лист
`assets/spritesheet.png` и процедурные кадры.

- `assets/generated/originals/` — исходные ImageGen-листы и эффекты.
- `assets/generated/frames-hd/` — отдельные кадры исходного разрешения.
- `assets/generated/frames-game-hd/` — готовые игровые текстуры 4×.
- `assets/generated/frames/` — компактные игровые текстуры 1×.
- `assets/generated/walk-preview.gif` — просмотр новых циклов ходьбы.
- `assets/generated/enemy-attacks-preview.gif` — просмотр атак монстров.
- `python3 tools/build_generated_sheet.py` — повторная нарезка обоих атласов (Pillow).
- Промпты и схема кадров: `ASSET_PROMPTS.md`; происхождение: `ATTRIBUTION.md`.

Поле рисуется как единая процедурная карта 1024×1024: приглушённая земля,
пятна золы, редкий сланец и тлеющие трещины. Сгенерированный тайл сохранён,
но не используется из-за заметных повторов и избыточного контраста.

## Структура

```
src/
  main.ts      — бутстрап PlayCanvas (орто-камера, земля, цикл), дебаг-режимы
  art.ts       — процедурный пиксель-арт (карты символов + палитра)
  textures.ts  — текстуры/материалы (unlit-спрайты: emissive + opacityMap)
  game.ts      — геймплей: волны, ИИ врагов (spatial hash), оружие, XP, апгрейды
  ui.ts        — DOM-оверлей: HUD, старт, левел-ап, смерть, победа
tools/
  build_alt_sheet.py — сборка assets/spritesheet.png из скачанных паков
assets/downloads/   — исходники паков (лицензии в ATTRIBUTION.md)
```

Технически: каждый спрайт — plane-примитив, повернутый к ортографической камере
(-90° по X), сортировка «художника» через смещение по Z от Y. Материалы —
StandardMaterial только с emissive (unlit) и альфой через `opacityMap`/канал `a`.
Пулы сущностей, spatial hash для расталкивания толпы и попаданий.
