# ATTRIBUTION

Набор в `assets/generated/` создан встроенным OpenAI ImageGen 2026-10-13
по промптам из `ASSET_PROMPTS.md` и уточнениям пользователя (листы персонажей,
12 кадров атаки). Точные промпты: `assets/generated/prompts.json` и
`assets/generated/slash-prompt.txt`. Исходники — `originals/`, отдельные кадры
исходного разрешения — `frames-hd/`, игровые версии — `frames/`.
Игра предпочитает этот набор; перечисленный ниже OpenGameArt-лист сохранён
для резервной загрузки. Процедурный арт остаётся резервом для отсутствующих кадров.

Ассеты в `assets/downloads/` скачаны с [OpenGameArt.org](https://opengameart.org)
и используются в соответствии с их лицензиями. Собранный из них лист:
`assets/spritesheet.png` (сборка: `tools/build_alt_sheet.py`).
